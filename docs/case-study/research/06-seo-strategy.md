## 2. On-page architecture for SEO

- **One page per format** (Zumba, Power Garba, Bokwa, Pilates, TRX/Functional, Yoga, Kids, Corporate) — each a landing page with: what it is, who it's for, timings, instructor, FAQs, reviews mentioning that format, booking CTA. This mirrors how searches actually happen (people search the format, not the studio).
- **Title patterns:** `Zumba Classes in Nagpur (Gokulpeth) | 2Stepz Fitness & Dance Studio` — format + city + locality + brand.
- **Local landing content**, not doorway spam: one genuine paragraph per page anchoring locality ("2 minutes from Times of India square, serving Gokulpeth, Dharampeth, Ramdaspeth…").
- **Internal linking:** Home → format pages (descriptive anchors: "Zumba classes in Nagpur", not "learn more") → schedule → trial booking; every blog post links to exactly one format page + the trial page; footer links to all format pages + NAP.
- **Schema markup:** `LocalBusiness`/`ExerciseGym` + `HealthClub` (NAP, geo, hours, sameAs → Instagram/Facebook/Justdial), `Person` for Madhumita (awards), `FAQPage` on FAQ + format pages, `Event` for workshops/masterclasses, `AggregateRating` only per Google's current review-snippet policies.
- **Media SEO:** real photos with descriptive filenames/alt ("zumba-class-gokulpeth-nagpur-2stepz.jpg"); compressed (WebP/AVIF); geotag consistency.

## 3. Google Business Profile ↔ site loop

- Attach the site; use UTM-tagged links to measure GBP-driven traffic.
- GBP booking button → /trial page (or WhatsApp deep link).
- Mirror the format-page names in GBP "Services."
- Weekly GBP post = weekly blog/reel repurposed.
- Review engine: post-class WhatsApp message with the direct Google-review short link; QR at reception; respond to every review with format keywords occurring naturally ("So glad you're loving the Power Garba batch!").

## 4. Citations & authority

- **NAP consistency sweep:** Justdial, Sulekha, IndiaMART, UrbanPro, Fitternity, FitPass, Gympik, youngbutterfly — one canonical name ("2Stepz Fitness & Dance Studio"), one address string, one number.
- **Press links:** The Live Nagpur and Nagpur Today already cover the studio — ask for links to the new site in future coverage; pitch a 10-year-anniversary story (est. 2015 → 2025/26 is a ready-made hook).
- **Zumba.com instructor directory** (if Madhumita holds ZIN licensure) — an authoritative, relevant backlink competitors won't have.
- Local partnerships (schools, corporates already served) → event recaps with links.
