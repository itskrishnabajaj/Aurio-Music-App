# Case study — internal only

This folder holds the discovery research that the 2Stepz website was designed from:
business audit, Google Business Profile audit, review analysis, competitor benchmarking,
SEO strategy, UX and conversion strategy, information architecture, and the build roadmap.

It is **internal project material**, kept for reference and portfolio use.

- It is not part of the website build.
- It is excluded from deployment via `.vercelignore`.
- Nothing in `app/` or `components/` imports or links to it, and it appears in no route,
  sitemap entry or metadata.

See [`research/`](./research) for the fifteen report sections.
